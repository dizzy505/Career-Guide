🚀 Project Overview
--------------------
CareerGuide.id is a rule-based expert system that recommends career paths based on user characteristic, skills, education, using a backward chaining inference method to simulate logical expert reasoning.

🛠️ Tech Stack
- Python
- Streamlit
- Backward Chaining

📋 How to Run
```bash
git clone https://github.com/dizzy505/Career-Guide.git
cd Career-Guide
pip install -r requirements.txt
streamlit run app.py
```

✨ Key Features
- Personalized career recommendations.
- Logical reasoning career paths.
- Interactive web app deployment.
